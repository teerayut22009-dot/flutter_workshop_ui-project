FLUTTER WORKSHOP UI PROJECT - READY FILES

ไฟล์ชุดนี้ทำตามหน้า E01-E06 และใช้รูปจาก resource ที่ส่งมาให้แล้ว

วิธีใช้กับโปรเจกต์เดิม:
1) แตก ZIP
2) เอาโฟลเดอร์ lib ไปแทน/รวมกับ lib ในโปรเจกต์ flutter_workshop_ui_project
3) เอาโฟลเดอร์ assets ไปไว้ที่ root ของโปรเจกต์
4) ใช้ pubspec.yaml ที่ให้มา หรือเช็กให้มี:
      assets:
        - assets/images/
5) เปิด Terminal ที่ root โปรเจกต์แล้วรัน:
      flutter pub get
      flutter run
